# BBBC048 v1 — SEANA experiment dataset

These images and labels are from BBBC048 v1, generated by the Flow Cytometry
Core Facility at Newcastle University, UK, and made available by Andrew Filby
through the Broad Bioimage Benchmark Collection:
https://bbbc.broadinstitute.org/BBBC048

This SEANA release selects the original `*_merged.jpg` composite images used
by its BBBC048 experiment loader: one image per cell, with labels taken from
the enclosing phase directory. The image bytes are unchanged. Per-channel
copies, unrelated upstream archives, denoised estimates and trained models
are not part of this dataset file. The original `Ground_truth.lst` is retained
for provenance; its numeric label ordering differs from the explicit
`manifest.json` phase vocabulary used by the SEANA experiments.

Added material consists of the manifest, image checksums and explicit split
indices. Indices refer to the ordered `records` array in `manifest.json`, which
also provides every cell's object ID and label. Random splits use the captured
stratified 80/20 algorithm with seeds 0, 1 and 2. Two object-ID-order split
policies are included as separate controls. Split assignments are reconstructed
from the captured loader; historical per-run membership files were not available.

Native 66×66 RGB composites are retained. Training applies its spatial
augmentations at runtime; probe inputs are resized/center-cropped to 64×64.
No clean-image targets or synthetic corruption are added.
